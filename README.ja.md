# getGamen

[English](README.md)

AI エージェントに、スクリーンショットの撮影から加工まで任せられる macOS アプリです。撮影、枠で囲む、クロップ、マスク、モザイクを CLI と MCP から実行できます。加工のたびに新しいファイルとして保存するので、各段階を人が開いて確かめられます。手で撮って編集する普通のスクリーンショットアプリとしても使えます。

macOS 14 以降の Apple シリコンと Intel の Mac に対応しています。ただし、macOS 14（Sonoma）の実機での動作確認はまだ行っていません。Swift、AppKit、SwiftUI、ScreenCaptureKit、Vision など Apple 純正の API だけで作っています。

## AI エージェントから使う

Claude Code や Codex などのエージェントには、getGamen を MCP サーバーとして登録するか、シェルから `getGamen` コマンドを呼ばせます。シェルから呼ぶときは、アプリ内の実行ファイルへのシンボリックリンクを PATH に置きます（手順は [CLI と MCP](docs/automation.md)）。MCP の登録例です。

```json
{
  "mcpServers": {
    "getGamen": {
      "command": "/Applications/getGamen.app/Contents/MacOS/getGamen",
      "args": ["mcp"]
    }
  }
}
```

エージェントは次の操作ができます。

- 画面とウインドウの一覧を取り、ウインドウ単位または範囲を指定して撮影する。
- 画像に枠・マスク・モザイクを付け、クロップする。位置は画像の画素で指定する。
- PNG・PNG8・JPEG に変換する。

たとえば「設定画面を撮って、保存ボタンを枠で囲み、メールアドレスにマスクをかけて」と頼むと、エージェントがウインドウを探して撮影し、加工した画像を保存します。

出力は毎回新しいファイルで、既存のファイルは上書きしません。撮影した原本、枠を付けた版、モザイクをかけた版が別々に残るので、手順書に貼る前に人が順に見比べられます。自動操作は画像をネットワークへ送らず、クリップボードにも入れません。通信するのは Lemon Squeezy でのライセンス確認だけで、送るのはライセンスキーとこの Mac のコンピュータ名です。

モザイクは見た目をぼかす効果で、元の情報を確実に消すものではありません。公開する画像から消したい情報には、塗りつぶしのマスクを使ってください。加工前の原本も別ファイルとして残るので、公開や共有に使うのは加工済みのファイルだけにしてください。

コマンドの一覧、座標の決まり、画面収録権限の扱いは [CLI と MCP](docs/automation.md)（英語）にまとめています。

## 導入

DMG を開き、getGamen を Applications へドラッグします。初回撮影時に「システム設定 > プライバシーとセキュリティ > 画面収録」で getGamen を許可し、getGamen を再起動してください。エージェントから撮影するときは、MCP ホストやターミナルのアプリにも同じ許可が要ることがあります。許可の確認方法は [CLI と MCP](docs/automation.md) の「Screen Recording permission」にあります。

作業データは `~/Library/Application Support/getGamen` に一時保存し、書き出した画像は設定で指定したフォルダ（既定は `~/Pictures/getGamen`）に保存します。更新時は新しい DMG からアプリを上書きします。

### SSEz から乗り換える場合

getGamen の旧名は SSEz です。

1. 旧 SSEz の設定で「ログイン時にSSEzを起動」をオフにし、「ログイン時には起動しません。」の表示を確認してから終了します。「設定を変更できません」などのエラーが出た場合は削除に進まず、先に「システム設定 > 一般 > ログイン項目」を確認してください。
2. `/Applications/SSEz.app` を削除します。
3. getGamen を起動し、画面収録を許可して再起動します。
4. 必要なら設定でログイン起動をオンにします。

バンドルIDと保存先が変わったため、設定と作業データは引き継ぎません。書き出し済みの画像は元のフォルダに残ります。旧データ `~/Library/Application Support/SSEz` と旧設定は、不要なら手で削除してください。

## 操作

- メニューバー、Dock、既定のControl+Option+Command+Spaceから撮影メニューを開きます。ウインドウ・範囲・前回範囲・手動スクロール撮影に対応します。
- 編集画面で枠、マスク、モザイク、クロップを選びドラッグします。選択ツールで移動、右下からサイズ変更、Shiftで複数選択できます。変更確定後に自動保存します。
- 画像の読み込み（ファイルメニュー・Dockへのドロップ）は原本をコピーして編集画面を開き、入力ファイルを変更しません。
- 一括変換は変換ごとの新規フォルダへ保存します。PNG8は実パレットPNG、JPEGの透明部分は白です。
- スクロール撮影は重なりを残しながら手動で下へ進めます。不確かな結合は停止し、途中データを保持します。最後に受理した画面位置へ戻して再開できます。
- 設定からショートカットの記録・解除・初期化とログイン起動を変更できます。

原本と編集情報は `~/Library/Application Support/getGamen` に一時保存し、編集画面を閉じると削除します。保存中・未保存のまま閉じた分、閉じずに終了した分、書き出しの記録は次回起動時に削除します。途中のスクロール画像も同じ場所に保持します。書き出した画像は出力先に残ります。

## ショートカット

macOS のショートカット.app で次のアクションを使えます。撮影の3つと撮影メニューは、Spotlight からも呼び出せます。

- ウインドウを撮影・範囲を撮影・前と同じ範囲を撮影: いつもの選択画面で撮り、撮った原本の PNG を返します。編集画面と自動書き出しも、いつもどおり行います。Esc で取り消すと、ショートカットはエラーで止まります。
- 撮影メニューを開く: 撮影メニューを表示します。
- 画像を変換: PNG・PNG8・JPEG（品質は 0〜1）に変換したファイルを返します。
- 画像をクロップ・枠で囲む・マスクをかける・モザイクをかける: 範囲は画像の画素で指定し、左上が原点です。Retina 画面で撮った画像は、幅と高さが画面上の見た目のそれぞれ2倍の画素になります。枠の色は #FF9500 のオレンジで、形（四角・角丸・円・楕円）と線の太さを選べます。結果は PNG で返し、元の画像は変えません。

例: 「範囲を撮影」→「枠で囲む」→「ファイルを保存」とつなぎ、「枠で囲む」の X・Y・幅・高さに枠を付けたい位置を指定すると、撮った画像にオレンジの枠を付けて保存できます。

ショートカットから起動・実行されたときは、前回の撮影モードを自動で始めません。画像を渡すアクションを初めて実行すると、ショートカット.app が画像の共有の許可を求めます。
